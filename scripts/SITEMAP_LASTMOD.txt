사이트맵 수정일(lastmod)

기존 페이지를 다시 만들지 않고 사이트맵 3개만 갱신:
  node scripts/update_sitemap_lastmod.js --write
검사:
  node scripts/test_sitemap_lastmod.js

규칙
- 커밋된 HTML과 내용이 같으면 해당 HTML의 마지막 Git 커밋 날짜를 사용한다.
- 미커밋 변경 또는 새 HTML은 실제 파일 저장 날짜를 사용한다.
- 한국 시간(Asia/Seoul), YYYY-MM-DD 형식이다.
- CRLF/LF 차이는 내용 변경으로 취급하지 않는다.
- 배포/사이트맵 재생성 시각만으로 날짜를 올리지 않는다.
- 기존 URL과 페이지 내용은 수정하지 않는다.
- 로컬 도시/읍면동/라우터 빌드 마지막에 자동 갱신한다.
- 관리자 배치 생성은 기존 사이트맵 날짜를 보존하고 GitHub의 기존 HTML과
  실제 생성 내용이 달라진 경우에만 현재 날짜를 기록한다.
- 내용 수정용 개별 스크립트를 실행한 뒤에는 위 갱신 명령도 실행한다.
- Git이 없거나 경로가 잘못되면 오류를 내므로 날짜가 추측되어 저장되지 않는다.
