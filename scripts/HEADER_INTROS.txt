상단 지역별 소개문 관리

저장 파일: netlify/functions/data/copier_header_intros.json
대상: 복합기 도시 227곳 + 읍면동 3,565곳. 라우터와 목록 페이지는 제외.

entries 아래 해당 URL 경로를 검색하여 text만 수정합니다.
읍면동 복합기 항목은 기본적으로 text를 메타 설명으로도 사용합니다.
개별 항목에 useAsMetaDescription: false를 설정하면 기존 메타 설명 규칙을 유지합니다.
도시·라우터 페이지의 메타 설명 규칙은 변경하지 않습니다.
region과 경로 키는 기존 값 그대로 유지합니다. 소개문은 HTML이 아닌 한 줄 텍스트입니다.

반영: node scripts/update_header_intros.js --write
검사: node scripts/update_header_intros.js

이미 저장한 문구는 자동으로 다시 만들지 않습니다. 최초 생성할 때만 조합합니다.
저장된 소개문은 기존 로컬 빌드와 관리자 생성 함수에서도 읽습니다.
--write는 기존 파일에서 site-header 안의 p 한 곳만 바꾸며,
title, meta description, canonical, 다른 본문, 사이트맵, RSS는 수정하지 않습니다.

문구 조건: 지역명으로 시작, 렌탈 문의, 4문장, 공백 포함 140~205자.
필수 단어: 칼라, 흑백, 복합기, 프린터, 복사기, 플로터, 임대, 렌탈, 대여, A3, A4.
마지막 문장은 플로터 별도 문의 안내입니다.
지역명만 바꾼 전체 문장 중복도 검사하지만 일부 문장은 반복됩니다.
조합의 차이가 실제 지역별 정보의 차이나 검색 노출 향상을 의미하지는 않습니다.
검증되지 않은 설치 실적, 지점, 방문 일정, 제공 보장 등은 작성하지 않습니다.

실제 배포 사이트 반영을 위한 커밋·푸시·배포는 별도 작업입니다.

라우터 소개문은 netlify/functions/data/router_header_intros.json에 따로 저장합니다.
수정할 경로의 text만 변경한 뒤 아래 명령으로 반영/검사합니다.
반영: node scripts/update_router_header_intros.js --write
검사: node scripts/update_router_header_intros.js
지역명으로 시작하는 4문장, 공백 포함 140~205자입니다.
건설현장, 임시사무실, AI교육, 단기, 라우터렌탈, 무선인터넷, 무선와이파이, 무선공유기를 포함합니다.
업무 상황은 이용자의 검토 항목이며 해당 지역의 설치 실적이나 서비스 보장이 아닙니다.
