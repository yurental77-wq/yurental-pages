읍면동 URL 변경 (2026-10-28)

복합기: /emd/부산-동구/초량제3동-복합기렌탈/
라우터: /router/emd/부산-동구/초량제3동-라우터렌탈/
시군구 목록도 /emd/부산-동구/, /router/emd/부산-동구/로 통일.
시도 목록과 기존 도시(/pages/, /router/익산/ 등) URL은 유지.

이동: node scripts/migrate_emd_urls.js --write
검사: node scripts/validate_emd_urls.js

기존 7,130개 읍면동 + 512개 시군구 목록 주소는
netlify/functions/data/emd_url_redirects.json에서 새 주소에 1:1로 연결.
_redirects의 6개 공통 규칙이 이전 요청을 emd-redirect 함수로 전달하고,
함수가 HTTP 301 + Location으로 응답한다. 새 정적 HTML은 우선 제공된다.
폴더형 URL, 끝 슬래시 없는 URL, index.html URL을 모두 처리한다.
임의 외부 URL 또는 등록되지 않은 이전 주소로는 이동하지 않는다.

기존 HTML은 삭제 후 재생성하지 않고 내용 그대로 새 위치에 옮긴다.
이전 index.html 파일만 제거하며, 이력은 Git에 남아 복구 가능하다.
페이지 본문, 제목, 설명, 요금, 사진, FAQ는 변경하지 않는다.
상대 경로, canonical, OG URL, JSON-LD, 목록/연관 링크, 소개문 저장 키,
사이트맵 URL과 lastmod는 함께 갱신한다.

Netlify 301 처리는 배포 후에 실제 도메인에서 동작한다.
일반 정적 로컬 서버는 _redirects/Netlify 함수를 해석하지 않는다.
로컬 새 URL은 정상적으로 직접 미리볼 수 있다.
